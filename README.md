# Band Minimal API 🎸

A high-performance API built with **.NET 10** for managing band and artist information. This project showcases the latest features in the .NET ecosystem, focusing on extreme performance, low overhead, and the modern C# 14 syntax.

---

## 1. 🚀 Tech Stack

* **Framework:** .NET 10 (Latest)
* **Approach:** Minimal APIs (Optimized for .NET 10 runtime)
* **ORM:** Entity Framework Core
* **Database:** SQLite
* **Documentation:** Swagger / OpenAPI (Microsoft.AspNetCore.OpenApi 10.0)
* **Language:** C# 14

---

## 2. 🏛️ Architecture & Patterns

This project highlights:
* **Modern Minimal APIs:** Using the latest .NET 10 performance optimizations for routing and dependency injection.
* **RESTful Standards:** Implementation of status codes, resource-based routes, and standardized JSON responses.

---

## 3. 📑 API Endpoints

| Verb   | Endpoint       | Description                       |
| :---   | :---           | :---                              |
| GET    | `/bands`       | Retrieves all registered bands    |
| POST    | `/bands`       | Create a new band    |
| PUT    | `/bands/{id}`       | Edit the name of a band    |
| DELETE    | `/bands/{id}`       | Sof delete a band    |
